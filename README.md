# python--Multiplication-Table-Generator
This simple Python script generates a multiplication table for a user-specified number, from 1 up to 12. 
How it Works: 

1. Input: The program asks the user to enter an integer. 
2. Logic: It uses a while loop to iterate from i = 1 to i = 12. 
3. Output: It prints the result of the multiplication in the format: n xi = result. 

🚀 Getting Started 
Prerequisites • Python 3 installed on your machine. 

Installation & Usage 
1. Copy the code into a file named : 
2. Run the program in your terminal: python main.py
3. Enter a number when prompted to see its 1 to 12 times table. 

📋 Example 
Input:  enter a number:5
Output: 
5 x 1 = 5
5 x 2 = 10
....
5 x 12 = 60
